# 踩坑紀錄

## 環境建置

| 狀況 | 原因 | 解法 |
|------|------|------|
| Git 未安裝 | 新環境 | `xcode-select --install`（macOS）|
| uv 安裝被封鎖 | 網路/權限限制 | 改用 `pip3 install` |
| Node.js 版本太舊 | 系統內建版本 | 安裝 LTS 版本（18+）|

## GitHub

| 狀況 | 原因 | 解法 |
|------|------|------|
| `gh --version` Access denied | OpenCode 讀取權限被擋 | 允許讀取後重跑 |
| `gh auth status` 未登入 | 尚未授權 | `gh auth login --web --git-protocol https` |
| GitHub MCP 無法連接 | `GITHUB_TOKEN` 未設定 | `export GITHUB_TOKEN=$(gh auth token)` |
| push 被拒絕 | 權限不足 | 檢查 `gh auth status` |

## NotebookLM

| 狀況 | 原因 | 解法 |
|------|------|------|
| `nlm: command not found` | uv 工具路徑未進 PATH | 重開終端機；將 `uv tool dir --bin` 加入 PATH |
| 登入後 `nlm doctor` 未認證 | session 過期 | 重跑 `nlm login` |
| 設定改了沒生效 | OpenCode 不會 hot-reload | 必須完全重啟 |

## Firebase

| 狀況 | 原因 | 解法 |
|------|------|------|
| Windows 上 npx 權限問題 | PowerShell 執行原則 | 使用 `npx.cmd` |
| MCP 設定變更後不生效 | 需重啟 | 重啟 Hermes Agent |
| `read_time cannot be in the future` | 時間參數問題 | 驗證時優先用 add/get/delete |

## MCP / 瀏覽器控制

| 狀況 | 原因 | 解法 |
|------|------|------|
| open-computer-use 不能用 npx 啟動 | 命令格式錯誤 | 必須用 `open-computer-use mcp` |
| Windows install-opencode-mcp 失敗 | POSIX shell 需求 | 手動編輯 opencode.json |
| Playwright 首次需下載瀏覽器 | 尚未快取 | 先執行 `npx playwright install chromium` |

## Obsidian

| 狀況 | 原因 | 解法 |
|------|------|------|
| 中文字元路徑顯示問號 | PowerShell 編碼限制 | 不影響 Hermes Agent 內部通訊 |
| 覆寫既有筆言 | 未先讀原檔 | 嚴格遵守「補缺，不覆蓋」原則 |

## Workflow

| 狀況 | 原因 | 解法 |
|------|------|------|
| 收工時沒有實質進度 | 對話只是問問題 | 回應「今天沒有實質進度，略過同步」 |
| 工作筆言內容不一致 | 未同步驗證 | 收工時執行 `diff` 驗證 |
