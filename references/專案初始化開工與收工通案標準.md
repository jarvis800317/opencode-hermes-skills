# 專案初始化開工與收工通案標準

> 適用於所有 Hermes Agent / OpenCode 專案工作流程

## 固定檔案

每個專案必備：
- `AGENTS.md` — 長期穩定規則與 SOP
- `<專案名>工作筆言.md` — 持續追加的進�、決策、驗證、待辦及踩坑
- `.gitignore` — 排除憑證、代理設定、快取

### Obsidian 路徑

```
~/我的雲端硬碟/2ndBrain/InitialProject/<專案名>工作筆言.md
```

本機與 Obsidian 工作筆言必須同名且內容一致。

## 觸發語句

| 語句 | 執行動作 |
|------|----------|
| 「開工」 | 讀取工作筆言、檢查 Git 狀態、輸出摘要 |
| 「收工」 | 盤點、寫入工作筆言、同步 Obsidian、commit + push |
| 「繼續」 | 讀取工作進度繼續工作 |

## 開工流程（只讀取）

1. 確認專案路徑
2. 讀取工作筆言
3. 檢查 Git 狀態
4. 輸出開工摘要
5. 等待使用者選擇方向

**不做**：git pull、commit、push、套件安裝、外部同步

## 收工流程（追加模式）

1. 盤點今天做了什麼
2. **追加**本機工作筆言（不覆蓋歷史）
3. 同步 Obsidian 並驗證
4. Git commit + push
5. 報告同步狀態

## 專案資料夾命名

- 英文小寫 + 連字號
- 例：`quality-plan-generator`、`taolin-tool`

## Git 預設設定

- 預設 `--private`，除非指定 `--public`
- 使用 `main` 作為預設分支

## 安全規則

- 安裝任何外部套件、skill、MCP 前，先做 Security Scan
- 對外訊息先出草稿，不直接送出
- 不把 API Key、token、憑證檔提交到版本庫

## 不 commit 的檔案

- `.codex/`、`.claude/`（代理設定）
- `node_modules/`
- `*.log`
- `.env`
- `*~`、`*.tmp`
- 私人來源文件及正式輸出文件
